The Student Performance Analysis System is a Python program used to manage and analyze student academic records. It allows users to add, display, and search student information such as ID, name, branch, and subject marks. The system calculates total marks, average marks, grades, class topper, and subject-wise statistics. It also performs statistical analysis like subject averages, standard deviation, and grade distribution. Student data can be saved to and loaded from a text file using Python file handling.
